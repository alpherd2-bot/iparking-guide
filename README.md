# 아이파킹 방문차량 예약 안내

GitHub Pages에 바로 게시할 수 있는 정적 웹사이트 파일입니다.

## 업로드 방법

1. GitHub에서 `iparking-guide`라는 Public 저장소를 만듭니다.
2. 이 압축파일을 풉니다.
3. 압축을 푼 폴더 안의 **모든 파일과 `assets` 폴더**를 저장소 최상위에 업로드합니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Source**는 `Deploy from a branch`, **Branch**는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
6. 게시가 끝나면 `https://깃허브아이디.github.io/iparking-guide/` 주소로 접속합니다.

## 주의사항

- `index.html`이 저장소의 가장 바깥쪽에 있어야 합니다.
- ZIP 파일 자체를 저장소에 올리지 말고, 반드시 압축을 푼 파일을 올려야 합니다.
- `assets` 폴더 안의 이미지와 QR 파일을 삭제하거나 이름을 바꾸지 마세요.
- 사이트 주소가 확정되면 아파트 게시 안내문의 QR코드를 새 주소로 교체해야 합니다.
